# HostHealthDetectionAndAlerts_by-Shellscript

## Linux 主機健康狀態檢查與安全偵測告警系統
本專案提供一套輕量級、模組化的 Shell 腳本系統，旨在幫助系統管理人員能快速、簡單且主動地管理 Linux 主機健康狀態，即時偵測硬體資源瓶頸、硬碟健康度與非預期開放的異常網路服務，並發出顏色化告警與自動記錄日誌。

## 🎯 研究目的
- 主動監控：定期自動檢查 Linux 主機核心資源（CPU、記憶體、磁碟空間與 SMART 健康度）
- 資安異常偵測：檢查網路連線狀態，並針對未經管理員授權的「非信任服務 Ports」進行即時掃描與告警
- 簡易管理：提供表單式互動選單，讓管理人員無需記憶複雜命令即可執行全套檢查
- 日誌歸檔：自動生成包含時間戳記的日誌檔並進行 Gzip 壓縮歸檔，便利後續稽核

## 💻 核心功能與腳本說明
1. 管理員選單介面 (admin_tool.sh)
   - 提供 CLI 表單選單，整合所有檢查項目，方便管理人員一鍵選擇與執行。

2. 磁碟空間檢查 (spaceCheck.sh)
   - 功能：掃描所有掛載點使用率。
   - 告警條件：使用率 $\ge 80\%$ 時發出紅色警告標示。

3. CPU 使用率檢查 (cpuCheck.sh)
   - 功能：即時計算 CPU 總使用率。
   - 告警條件：CPU 使用率 $> 90\%$ 時發出警告。

4. 記憶體使用率檢查 (memoryCheck.sh)
   - 功能：計算系統 RAM 使用百分比。
   - 告警條件：記憶體使用率 $> 80\%$ 時發出警告。

5. 硬碟 SMART 健康狀態檢查 (diskHealthCheck.sh)
   - 功能：遍歷系統實體磁碟並檢查其 SMART 健康狀態報告。

6. 信任服務與網路狀態檢查 (networkCheck.sh)
   - 功能：測試外網連線（8.8.8.8），並驗證管理者設定的信任服務 Port（如 SSH 22, HTTPS 443, MySQL 3306）是否正常開啟。自動寫入日誌並執行 Gzip 壓縮。
  
7. 異常服務偵測告警 (abnormalDetect.sh)
   - 功能：主動掃描常見服務 Ports（如 HTTP 80, FTP 21, PostgreSQL 5432 等），若發現未經允許的 Port 被開啟，即判定為異常服務並發出告警通知。
  
## 🚀 快速開始與使用說明
- 系統需求操作系統：Linux (如 Kali Linux, Ubuntu, Debian, CentOS 等)  
- 必要工具：smartmontools (smartctl), bc, iproute2 (ss), gzip

安裝與執行權限
1. 複製專案到本地端：
‵‵‵
Bash
git clone https://github.com/your-username/linux-health-security-monitor.git
cd linux-health-security-monitor
‵‵‵

3. 設定腳本執行權限：

Bash
chmod +x *.sh

3. 執行管理介面
Bash
./admin_tool.sh
