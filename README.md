# HostHealthDetectionAndAlerts_by-Shellscript

## Linux 主機健康狀態檢查與安全偵測告警系統
本專案提供一套輕量級、模組化的 Shell 腳本系統，旨在幫助系統管理人員能快速、簡單且主動地管理 Linux 主機健康狀態，即時偵測硬體資源瓶頸、硬碟健康度與非預期開放的異常網路服務，並發出顏色化告警與自動記錄日誌。

🎯 研究目的
- 主動監控：定期自動檢查 Linux 主機核心資源（CPU、記憶體、磁碟空間與 SMART 健康度）
- 資安異常偵測：檢查網路連線狀態，並針對未經管理員授權的「非信任服務 Ports」進行即時掃描與告警
- 簡易管理：提供表單式互動選單，讓管理人員無需記憶複雜命令即可執行全套檢查
- 日誌歸檔：自動生成包含時間戳記的日誌檔並進行 Gzip 壓縮歸檔，便利後續稽核

🔄 系統架構與運作流程
系統支援手動選單操作與 Crontab 排程自動化執行兩種模式。
所有監控結果將即時顯示於終端機，並自動壓縮儲存至日誌目錄中。
